# 🎬 Netflix Clone (React + Vite)

A Netflix-inspired movie streaming UI built using **React, Vite**, and **TMDB API**.  
This project showcases dynamic movie lists, YouTube trailers, hover animations, and responsive layouts just like Netflix.

## 🚀 Features

✔️ Netflix-style UI with row-based movie categories
✔️ Responsive movie posters & hover effects
✔️ Fetch movie data using **TMDB API**  
✔️ Play trailers via **YouTube**
✔️ Axios custom instance for requests  
✔️ Banner section showcasing featured movie


## 🛠️ Tech Stack

  Tech-Usage
  React:- UI & components
  Vite:- Fast dev server + build tool  
  Axios:- API requests
  TMDB API:- Movie data
  CSS:- Styling
  Movie Trailer + YouTube Trailer popups
